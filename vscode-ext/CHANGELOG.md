# Change Log

All notable changes to the "solarcode" extension will be documented in this file.

## [0.0.9] - 2025/09/06

- Initial release of the "solarcode" extension
- Features sharable links to GitHub codespaces for easy collaboration
- Allows creating beautiful screenshots of code snippets for sharing on social media

## [0.0.10] - 2025/09/06

- Bugfix: The previous version was bundled incorrectly, missing important resources.
  This update includes all necessary files for the extension to function properly.

## [0.0.11] - 2025/09/06

- Maintenance update. This update does not include any changes.
  The previous version was not correctly deployed due to CI issues.
  This update ensures that the extension is properly deployed.

## [0.0.12] - 2025/09/06

- Centered the screenshot preview for a more polished look.

## [0.0.13] - 2025/09/06

- Added some spacing between UI components for better readability.

## [1.0.0] - 2026/03/06

- No more 301 redirects! All links now point directly to GitHub codespaces.
  Old links will still work for backwards compatibility.
